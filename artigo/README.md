# Artigo de TCC — Marília Stefenon Rodrigues

Template SBC. Esta pasta contém **uma única versão ativa** do artigo.

## Estrutura

| Caminho | Conteúdo |
|---|---|
| `main.tex` | Artigo atual (era `artigo_final_9.tex`) |
| `sbc-template.sty` | Template SBC |
| `figuras/` | Figuras e telas usadas no artigo |
| `versoes-anteriores/` | Cópias antigas, só para consulta (não compilam: caminhos de imagem antigos) |
| `apoio/artigo-exportado.html` | Exportação HTML do artigo, não faz parte da compilação |

## Regra daqui para frente

Não criar `artigo_final_10.tex`, `(11)` etc. A versão é sempre `main.tex` e o histórico fica no git
(um commit por rodada de revisão). As Notas de orientação continuam na raiz do repositório e não mudam.

## No Overleaf

Depois de puxar estas mudanças, definir **Menu → Main document → `artigo/main.tex`** e conferir se compila.
